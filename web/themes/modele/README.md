# Template theme

Duplicate this theme from RL-UI (OBS overlays > Themes > Customize), then:

- replace `images/fond-compteur.svg` and `images/logo.svg` with your own images;
- put your colors in `theme.json`;
- add your font to `fonts/` and your sounds to `sounds/` (see `theme.css`).

To share your theme: “Export” button -> a .zip file that others install with “Install a theme”.

Full guide (every element you can change): https://github.com/MaximeKwk/rl-ui/blob/main/docs/THEMES.md
