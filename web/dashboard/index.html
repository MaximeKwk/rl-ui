Qui est « toi » ?

MMR

Le vrai MMR est lu dans le journal du jeu à chaque fois que tu lances une recherche de partie (seul ou chef de groupe). En fin de match, la variation est d'abord estimée d'après tes vraies variations récentes, puis corrigée dès que le jeu donne la valeur réelle.

Application

Démarrage en 3 étapes

  1. Stats API de Rocket League. Elle est activée d'office dans les versions récentes du jeu. Sinon : Réglages → « Activer / réparer l'API », puis relance Rocket League. Aucun mod, pas de BakkesMod, compatible EAC.
  2. Joue. L'app reconnaît ton compte grâce au journal du jeu, puis compte chaque victoire / défaite, les overtimes, le mode (2v2 classé, 3v3…), le MVP et les abandons.
  3. Ajoute les overlays dans OBS ou Streamlabs (onglet Overlays OBS) : le compteur (horizontal, vertical ou collé à la jauge de boost), les alertes plein écran, les dernières parties et le récap de fin de stream.

Questions fréquentes

Une partie n'a pas été comptée

Vérifie le journal (onglet Session) : la partie est peut-être d'un mode exclu (partie privée, hors-ligne…) ou le tracker était en pause. Tu peux toujours corriger avec les boutons + / −.

« Stats API : fermé » alors que le jeu est lancé

Le jeu n'ouvre l'API qu'une fois lancé avec PacketSendRate > 0. Clique sur « Activer / réparer l'API » dans les Réglages puis redémarre complètement Rocket League (après une mise à jour du jeu aussi).

Les alertes ne font pas de son sur le stream

Dans les propriétés de la source navigateur OBS, coche « Contrôler l'audio via OBS », puis règle le volume de la source dans le mélangeur audio.

Le compteur « Boost » n'est pas bien aligné sur ma jauge

Overlays OBS → Compteur : active « Afficher le repère de la jauge », puis règle la taille du HUD et les décalages jusqu'à ce que le repère recouvre ta jauge dans l'aperçu d'OBS. Désactive ensuite le repère. La source doit faire la taille de ton canevas (ex. 1920 × 1080).

Actions automatiques avec Streamlabs

Onglet Actions stream → Logiciel : Streamlabs Desktop. Dans Streamlabs : Paramètres → Contrôle à distance → clic sur le QR code → Afficher les détails → copie le jeton de l'API.

Setup avec 2 PC

Active « Accessible depuis le réseau local » (Réglages → Serveur local) et utilise l'adresse IP du PC de jeu dans les URL des overlays sur le PC de stream. Autorise l'app dans le pare-feu Windows si demandé.

Je joue en duo, ça compte bien pour moi ?

Oui : l'app suit ton compte à toi (l'ID Steam/Epic lu dans le journal du jeu), pas celui de ton mate.

D'où vient le MMR ?

Du journal du jeu : quand tu lances une recherche de partie (seul ou chef de groupe), Rocket League y écrit ton MMR pour ce mode. La variation d'un match est donc connue à la recherche suivante ; en attendant, l'app affiche une estimation basée sur tes vraies variations récentes (marquée ≈ dans le tableau de bord). Si c'est ton mate qui lance la recherche, seule l'estimation est disponible.
