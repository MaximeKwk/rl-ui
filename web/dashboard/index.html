Stream

What RL-UI does in your streaming software and in your chat.

Streaming software

In OBS: Tools → WebSocket Server Settings → tick “Enable WebSocket server”, then “Show Connect Info” to copy the password.

In Streamlabs Desktop: Settings → Remote Control → click the QR code → Show details, then copy the API Token below. The port is 59650 by default.

Automatic actions

Example: show a “Hype cam” source for 8 s on overtime, or switch to a “Victory” scene and come back automatically.

Twitch chat commands

Viewers type !wl, !mmr, !last… and RL-UI answers in your chat with your live stats. No bot to install: connect your Twitch account below and RL-UI answers in your own channel.

In the answers: {name} {w} {l} {lw} {ll} {wr} {streak} {best} {otw} {otl} {mvp} {goals} {played} {mmr} {mmrd} {playlist} {last}. Leave an answer empty to use the default one.

    Help

    Get started, find a feature, fix a problem.

    What RL-UI can do

    Click a card to go there

    Get started in 3 steps

    1. Rocket League Stats API. It is enabled by default in recent versions of the game. Otherwise: Settings → “Enable / repair the API”, then restart Rocket League. No mods, no BakkesMod, EAC-compatible.
    2. Play. The app recognizes your account from the game log, then counts every win / loss, overtimes, the mode (2v2 ranked, 3v3…), MVPs and early leaves.
    3. Add the overlays in OBS or Streamlabs (Overlays tab): the counter (horizontal, vertical or next to the boost gauge), full-screen alerts, recent matches and the end-of-stream recap.

    FAQ

    A match wasn't counted

    Open Diagnostic: every match the game reported is listed there with the reason it was counted or not (excluded mode, tracking paused, account not recognized…), and a button to count it afterwards with its real score.

    “Stats API: closed” while the game is running

    The game only opens the API when started with PacketSendRate > 0. Click “Enable / repair the API” in Settings, then fully restart Rocket League (also after a game update).

    Alerts have no sound on stream

    In the OBS browser source properties, tick “Control audio via OBS”, then set the source volume in the audio mixer.

    The “Boost” counter isn't aligned with my gauge

    Overlays → Counter: turn on “Show the gauge guide”, then adjust the HUD size and offsets until the guide covers your gauge in the OBS preview. Then turn the guide off. The source must be the size of your canvas (e.g. 1920 × 1080).

    Automatic actions with Streamlabs

    Stream tab → Software: Streamlabs Desktop. In Streamlabs: Settings → Remote Control → click the QR code → Show details → copy the API token.

    2-PC setup

    Turn on “Reachable from the local network” (Settings → Local server) and use the gaming PC's IP address in the overlay URLs on the streaming PC. Allow the app in the Windows firewall if asked.

    I play duos, does it count for me?

    Yes: the app follows your own account (the Steam/Epic ID read from the game log), not your teammate's.

    Where does the MMR come from?

    From the game log: when you start a matchmaking search (solo or party leader), Rocket League writes your MMR for that mode. So the change of a match is known at the next search; meanwhile, the app shows an estimate based on your recent real changes (marked ≈ in the dashboard). If your teammate starts the search, only the estimate is available.
