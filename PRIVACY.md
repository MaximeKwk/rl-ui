# RL-UI privacy policy

*Last updated: September 30, 2026* · [Version française plus bas](#politique-de-confidentialité-de-rl-ui)

RL-UI is a desktop application made by Zoxam. It runs entirely on your computer.

- **No personal data is collected, sold or shared.** RL-UI has no account, no telemetry, no analytics and no advertising.
- **What stays on your computer:** your match history, settings, MMR values and themes are stored locally in the app's data folder (`%APPDATA%\RL-UI`). You can delete them at any time.
- **What RL-UI reads:** the official Rocket League Stats API (sent by the game on your own computer) and the game's local log file, to detect your matches, your account name and your MMR.
- **Local network:** RL-UI runs a small web server on your computer (`127.0.0.1`) so OBS or Streamlabs can display the overlays. It is only reachable from other devices if you turn on “Reachable from the local network”.
- **Connections you set up yourself:** if you enable them, RL-UI connects to OBS Studio or Streamlabs Desktop on your computer, and to the chat services you connect (for example Twitch) to answer chat commands. Only what these features need is sent (for example, a chat reply with your session record).
- **Updates:** the installed version checks GitHub for new versions (github.com/MaximeKwk/rl-ui). GitHub may log this request like any web request. The Microsoft Store version is updated by the Store.

Questions: open an issue at https://github.com/MaximeKwk/rl-ui/issues.

## Politique de confidentialité de RL-UI

*Dernière mise à jour : 30 septembre 2026*

RL-UI est une application de bureau créée par Zoxam. Elle fonctionne entièrement sur ton ordinateur.

- **Aucune donnée personnelle n'est collectée, vendue ou partagée.** Pas de compte, pas de télémétrie, pas de statistiques d'usage, pas de publicité.
- **Ce qui reste sur ton ordinateur :** ton historique de parties, tes réglages, tes valeurs de MMR et tes thèmes sont enregistrés localement dans le dossier de données de l'application (`%APPDATA%\RL-UI`). Tu peux les supprimer à tout moment.
- **Ce que RL-UI lit :** la Stats API officielle de Rocket League (envoyée par le jeu sur ton propre ordinateur) et le fichier journal local du jeu, pour détecter tes parties, ton pseudo et ton MMR.
- **Réseau local :** RL-UI lance un petit serveur web sur ton ordinateur (`127.0.0.1`) pour qu'OBS ou Streamlabs affichent les overlays. Il n'est accessible depuis d'autres appareils que si tu actives « Accessible depuis le réseau local ».
- **Connexions que tu actives toi-même :** si tu les actives, RL-UI se connecte à OBS Studio ou Streamlabs Desktop sur ton ordinateur, et aux services de chat que tu relies (par exemple Twitch) pour répondre aux commandes du chat. Seul ce dont ces fonctions ont besoin est envoyé (par exemple une réponse dans le chat avec ton bilan de session).
- **Mises à jour :** la version installée vérifie les nouvelles versions sur GitHub (github.com/MaximeKwk/rl-ui). GitHub peut enregistrer cette requête comme toute requête web. La version Microsoft Store est mise à jour par le Store.

Questions : ouvre une issue sur https://github.com/MaximeKwk/rl-ui/issues.
